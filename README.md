# Shooter-3D-Web
Línea de Fuego es un videojuego FPS 3D web de acción táctica en primera persona. Desarrollado en HTML5, CSS3 y JavaScript empleando WebGL y Canvas para el renderizado 3D en tiempo real. La arquitectura de su código gestiona el ciclo de renderizado, detección de colisiones, físicas, lógica de IA enemiga y estado del juego directamente en el cliente.
